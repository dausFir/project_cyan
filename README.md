# Reset Uang Gajian

Landing page interaktif untuk ebook keuangan pribadi oleh **Mr. Cuan**.

## Menjalankan lokal

Buka `dist/index.html` langsung di browser, atau layani folder proyek menggunakan static server.

## Struktur

- `dist/` — landing page statis
- `dist/assets/` — visual pendukung
- `.openai/hosting.json` — konfigurasi hosting
